# Пример разработки контрола: дерево задач на исполнение поручения
Репозиторий с шаблоном разработки "Пример разработки контрола: дерево задач на исполнение поручения".

## Описание
> [!NOTE]
> Решение можно использовать в качестве примера разработки своих контролов.

Решение позволяет сотрудникам просматривать состояние задач на исполнение поручения в виде дерева.
В узлах отображается минимальная информация по задаче:
1. Сокращенная тема задачи. Оформлена в виде ссылки для удобного перехода в карточку задачи.
2. ФИО исполнителя.
3. Срок задачи.
4. Контур узла:
    * Синий контур  - задача в работе;
    * Синий контур с кружком в углу  - текущая задача в работе;
    * Красный контур - задача прекращена;
    * Зеленый контур - задача выполнена;

Перед началом работы с деревом необходимо настроить представление формы для **Задачи на исполнение поручения**. Для этого необходимо добавить в карточку новую вкладку и разместить на ней специальный контрол "Дерево". Пример предоставлен ниже:

<img width="1670" height="433" alt="image" src="https://github.com/user-attachments/assets/7200a04d-545e-4b45-adc5-af12abe1b1fe" />

В состав решения входит:
1. Перекрытие задачи на исполнение поручения (**ActionItemExecutionTask**).
2. В задачу добавлено новое свойство **SuperiorTask**. В нем заполняется ссылка на родительскую задачу на исполнение поручения.
3. Добавлен новый модуль **Tree**. В нем реализована функция интеграции **GetTreeStructureActionItemExecutionTask**, которая возвращает данные для построения дерева в стороннем контроле.
4. В папке remote_component-tree-view содержатся исходники стороннего контрола. За основу был взят пример [стороннего контрола](https://github.com/DirectumCompany/sungero-remote-component-example-react).
5. Для реализации построения дерева используется библиотека [react-d3-tree](https://www.npmjs.com/package/react-d3-tree).

## Компоненты для сборки и разработки стороннего контрола
1. Для разработки стороннего контрола необходимо установить **node.js**, а также стороннюю среду разработки для работы с JavaScript. Например: Visual Studio Code.
2. Склонировать репозиторий с rx-template-actionitem-tree-view в папку. Исходники со сторонним контролом будут расположены в папке remote_component-tree-view.
3. Установите пакеты проекта, для этого в командную строку среды разработки введите команду "**npm i**". Это также можно сделать и через обычную командную строку системы, перейдя в папку со сторонним контролом.
4. Для отладки стороннего контрола используйте команду "**npm run start:dev:standalone**". После этого перейдите по адресу http://localhost:3001/.
> [!NOTE]
> При отладке потребуются данные для построения дерева. Вариант временной доработки для получения данных:
> -  В методе **ExecuteGetRequestAsync** добавить в headers способ авторизации;
> ```js
> async function ExecuteGetRequestAsync(url: string) {
>    const response = await fetch(url, {
>      headers: {
>        'Authorization': 'Basic ' + btoa('Administrator:11111')
>      }
>    });
>    if (!response.ok) {
>      throw new Error(`HTTP error! status: ${response.status}`);
>    }
>    return response.json();
> }
>```
> -  В методе **GetAllActionItemExecutionTaskForLeadTaskAsync** указать ид конкретной задачи.
> -  В config.yml у Directum RX укажите в разделе сервиса интеграции адрес http://localhost:3001/ в параметре **CORS_ALLOWED_ORIGINS_LIST**, чтобы не возникали проблемы с CORS политиками. Подробности в [справке](https://club.directum.ru/webhelp/directumrx/web/index.html?admin_config_integrationservice_linux.htm).
5. Для сборки стороннего контрола используйте команду "**npm run build:release**". В результате в папке dist будет создан ряд файлов для загрузки в DDS.

## Варианты расширения функциональности на проектах
1.	Расширение структуры для передачи дополнительных данных в сторонний контрол.
2.	Доработка узла **NodeContent** для отображения дополнительной информации по задаче или изменения дизайна.
3.	Реализация логики с вертикальным отображением. JSX объект **Tree** принимает в качестве параметра ориентацию дерева (**orientation**).

Более подробно про варианты расширения функциональности можно узнать в документации библиотеки [react-d3-tree](https://www.npmjs.com/package/react-d3-tree).

## Порядок установки
Для работы требуется установленный Directum RX версии 25.2 и выше.

## Установка для ознакомления
1. Склонировать репозиторий с rx-template-actionitem-tree-view в папку.
2. Указать в config.yml в разделе DevelopmentStudio:
```xml
   GIT_ROOT_DIRECTORY: '<Папка из п.1>'
   REPOSITORIES:
      repository:
      -   '@folderName': 'work'
          '@solutionType': 'Work'
          '@url': https://github.com/DirectumCompany/rx-template-actionitem-tree-view.git'
      -   '@folderName': 'base'
          '@solutionType': 'Base'
          '@url': ''
```

## Установка для использования на проекте
Возможные варианты

**A. Fork репозитория**
1. Сделать fork репозитория rx-template-actionitem-tree-view для своей учетной записи.
2. Склонировать созданный в п. 1 репозиторий в папку.
3. Указать в config.yml в разделе DevelopmentStudio:
```xml
   GIT_ROOT_DIRECTORY: '<Папка из п.2>'
   REPOSITORIES:
      repository:
      -   '@folderName': 'work'
          '@solutionType': 'Work'
          '@url': https://github.com/DirectumCompany/rx-template-actionitem-tree-view.git'
      -   '@folderName': 'base'
          '@solutionType': 'Base'
          '@url': ''
```

**B. Подключение на базовый слой.**

Вариант не рекомендуется, так как при выходе версии шаблона разработки не гарантируется обратная совместимость.
1. Склонировать репозиторий rx-template-actionitem-tree-view в папку.
2. Указать в config.yml в разделе DevelopmentStudio:
```xml
   GIT_ROOT_DIRECTORY: '<Папка из п.1>'
   REPOSITORIES:
      repository:
      -   '@folderName': 'work'
          '@solutionType': 'Work'
          '@url': '<Адрес репозитория для рабочего слоя>'
      -   '@folderName': 'base'
          '@solutionType': 'Base'
          '@url': ''
      -   '@folderName': 'base'
          '@solutionType': 'Base'
          '@url': 'https://github.com/DirectumCompany/rx-template-actionitem-tree-view.git'
```

**C. Копирование репозитория в систему контроля версий.**

Рекомендуемый вариант для проектов внедрения.
1. В системе контроля версий с поддержкой git создать новый репозиторий.
2. Склонировать репозиторий <Название репозитория> в папку с ключом `--mirror`.
3. Перейти в папку из п. 2.
4. Импортировать клонированный репозиторий в систему контроля версий командой:
`git push –mirror <Адрес репозитория из п. 1>`
