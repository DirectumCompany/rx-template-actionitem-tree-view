## Воркараунды

### WORKAROUND-01: z-index хардкод

- **Файлы:** `demo-view.module.css:316,386,405`
- **Проблема:** API хоста не предоставляет переменных или API для управления z-index
  порталов (модалки, тултипы, тосты), которые рендерятся через `createPortal`
  в `document.body`
- **Решение:** захардкожены значения с запасом: модалка `10000`, тултип `10001`
  (над модалкой), тост `10002` (поверх всего)
- **Предлагаемое решение:** хост предоставляет CSS-переменные
  `--host-zindex-modal`, `--host-zindex-tooltip`, `--host-zindex-toast` или API
  `registerLayer(name, zIndex)`

### WORKAROUND-02: getBoundingClientRect для тултипа

- **Файлы:** `tooltip.tsx:33`
- **Проблема:** API хоста не предоставляет механизм позиционирования всплывающих
  элементов относительно триггера
- **Решение:** ручной расчёт координат через `getBoundingClientRect()` + подписка
  на `resize`/`scroll` для пересчёта позиции при изменении viewport
- **Предлагаемое решение:** хост предоставляет хук `usePortalPosition(ref)` или
  `<FloatingPortal>` с автоматическим позиционированием

### WORKAROUND-03: Escape/фокус/скролл в модалке вручную

- **Файлы:** `modal.tsx:25-34`
- **Проблема:** API хоста не предоставляет компонент модального окна с focus trap,
  закрытием по Escape и блокировкой скролла страницы
- **Решение:** ручная реализация: `addEventListener('keydown')` для Escape,
  сохранение/восстановление `activeElement`, `document.body.style.overflow = 'hidden'`
- **Предлагаемое решение:** хост предоставляет `<HostModal>` или хук `useModal()`
  с готовым focus trap и блокировкой скролла

### WORKAROUND-04: принудительная установка имени логгера

- **Файлы:** `set-logger-name.ts`, `use-card-api.ts`, `use-cover-api.ts`
- **Проблема:** интерфейс `ILogger` не предоставляет свойства `name` и метода для его
  изменения. Имя логгера жёстко задано хостом как `"RemoteControl"`, все
  remote-компоненты логируются под одним именем
- **Решение:** принудительная запись в свойство `name` через
  `Object.getOwnPropertyDescriptor` для проверки `writable` и каст для обхода
  типобезопасности. При неудаче логируется предупреждение
- **Предлагаемое решение:** хост предоставляет API для задания имени логгера
  компонентом
